# castle

:wave:

This is my personal public webspace's repository. Here you'll see all the code used to construct what I'm calling `castle`.

> [!WARNING]
> **Work In Progress**

## Overview

- `/src/` - application directory
- `/src/blog` - markdown blog posts
- `/src/public` - available files within
- `/src/srcipts` - client javascript entry and modules
- `/src/styles` - client stylesheets css/scss
- `/src/views` - client pug templates
- `/utils` - internal methods and helpers
